О модуле Piper TTS



v [#VERSION#]

Модуль Piper TTS для системы умного дома Majordomo.

Обеспечивает синтез русской речи на основе нейросетевого движка Piper (VITS/ONNX). Поддерживает локальный запуск и подключение к удалённому HTTP API Piper. Включает нормализацию текста: числа прописью, единицы измерения с русскими окончаниями, часовые пояса, аббревиатуры.
