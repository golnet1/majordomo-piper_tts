Описание настроек

Общее

Piper TTS — модуль синтеза русской речи для MajorDoMo. Использует Piper (движок TTS на основе нейросетей) для преобразования текста в речь. Поддерживает локальный запуск Piper на сервере и подключение к удалённому HTTP API Piper.

В заголовке модуля отображаются цветные индикаторы состояния:

  • зелёный — компонент работает;
  • красный — компонент недоступен.
  • Подключен / Не подключен — в локальном режиме проверяет наличие /usr/local/bin/piper; в удалённом — доступность HTTP API по указанному адресу.
  • Установлено / Установка / Не установлено — статус Piper на сервере. Отображается только на 64-битных системах в локальном режиме.
Piper (локальный путь или IP:порт)
Назначение
Указывает, как модуль будет запускать Piper: локально через бинарник или через HTTP API на удалённом сервере.
Локальный режим
Введите путь к исполняемому файлу Piper, например /usr/local/bin/piper. Если поле оставить пустым, подставится /usr/local/bin/piper автоматически.
Удалённый режим
Введите IP-адрес или hostname сервера с HTTP API Piper, например 192.168.1.100:5000 или piper.local. Если порт не указан, по умолчанию используется 5000. В этом режиме модуль отправляет POST-запросы на http://адрес:порт/ с параметрами text, voice и length_scale.
Как определяется режим
Если значение поля содержит /, . или \ — считается локальным путём. Если содержит только цифры, точки и двоеточия (похоже на IP:port) — считается удалённым адресом.
Что меняется в интерфейсе
В удалённом режиме скрываются поля «Директория моделей», «Управление моделями» и кнопка «Установить Piper», так как HTTP API Piper не поддерживает эти операции.
Директория моделей
Назначение
Путь к папке, где хранятся голосовые модели (.onnx и .onnx.json).
Значение по умолчанию
Если поле пустое — подставляется /opt/piper/voices.
Структура
Модели должны быть разложены по подкаталогам: {models_dir}/ru_RU-{голос}-{качество}/ru_RU-{голос}-{качество}.onnx. Например: /opt/piper/voices/ru_RU-irina-medium/ru_RU-irina-medium.onnx.
Примечание
Поле отображается только в локальном режиме. В удалённом режиме модели хранятся на удалённом сервере.
Модель (.onnx)
Назначение
Выбор голосовой модели для синтеза речи.
Локальный режим
Выпадающий список заполняется на основе файлов .onnx, найденных в «Директории моделей». Название модели отображается как голос / качество, значение — полный путь к .onnx файлу.
Удалённый режим
Список голосов загружается через HTTP API (GET /voices). Значение — имя модели (например ru_RU-irina-medium), которое передаётся в параметре voice при синтезе.
Рекомендуемая модель
irina / medium — русский женский голос, хорошее качество при умеренном потреблении ресурсов (~200 МБ ОЗУ). Для слабых устройств — irina / low.
Скорость (Length Scale)
Назначение
Регулирует темп речи. Значение меньше 1.0 — быстрее, больше 1.0 — медленнее.
Диапазон
от 0.50 (очень быстро) до 1.50 (очень медленно). По умолчанию 1.00.
Примеры
0.80 — ускоренное чтение;
1.20 — размеренное, чёткое произношение;
1.50 — максимально медленно, для длинных текстов.
Как работает
Параметр передаётся в Piper как --length-scale (локально) или в HTTP-запросе как length_scale (удалённо).
Пауза между предложениями
Назначение
Добавляет паузу (в секундах) между предложениями в синтезированном тексте. Полезно для длинных текстов, чтобы речь звучала естественнее.
Диапазон
от 0.00 (без паузы) до 0.50 секунд. По умолчанию 0.10.
Как работает
Текст разбивается на предложения, каждое синтезируется отдельно, затем склеивается с указанной паузой.
Кэш
Сохранять кэш
Если включено, каждая синтезированная фраза сохраняется в файл. При повторном запросе той же фразы звук берётся из кэша, а не синтезируется заново. Значительно ускоряет повторяющиеся фразы (например, температура, время).
Удалять редкоиспользуемые фразы
Если включено, модуль автоматически удаляет файлы кэша, к которым не было обращений более 10 дней. Полезно для экономии места на диске и удаления устаревших записей (например, прогнозов погоды).
Директория кэша
Путь к папке с кэшированными аудиофайлами. По умолчанию /tmp/piper-tts. Убедитесь, что на диске достаточно места (хотя бы ~1 ГБ).
WebSocket port
Назначение
Порт WebSocket-сервера, который передаёт синтезированное аудио в браузер для воспроизведения. Если порт не указан — WebSocket не запускается, и звук воспроизводится через плеер AJAX.
Рекомендации
Обычно 8090. Убедитесь, что порт не занят другим сервисом, и что он открыт в файрволе. Для SPA-панелей (mboard_pro) используйте WebSocket, так как AJAX-плеер может не работать корректно в динамических интерфейсах.
Подключение плеера
На обычных страницах MajorDoMo скрипт плеера подключается автоматически. На SPA-панелях добавьте в index.html перед </body>:
<script src="/templates/piper_tts/js/piper_tts.js"></script>
Управление моделями

Раздел доступен только в локальном режиме. Позволяет установить или удалить голосовые модели для Piper.

Установка
Нажмите «Установить» для выбранной модели. Модуль скачает .onnx и .onnx.json с Hugging Face в «Директорию моделей». Прогресc отображается модальным окном.
Удаление
Нажмите «Удалить» — файлы модели будут стёрты с диска.
Доступные голоса
Список предопределён: irina, denis, dmitry, kseniya, natasha, nikita, rustam, vlad, yuriy. Каждый доступен в качествах low, medium и (для некоторых) high.

Системные требования и 32/64-битные системы

Архитектура

Локальный Piper (бинарник или pip-пакет) устанавливается только на 64-битных системах: x86_64, amd64, aarch64.

Сам модуль MajorDoMo устанавливается на любую архитектуру, включая 32-битные: armv7l, i686.

На 32-битных системах кнопка «Установить Piper» и раздел «Управление моделями» автоматически скрыты.

Рекомендация для 32-битных систем: используйте удалённый режим — установите Piper на отдельный 64-битный сервер (или ПК) и подключитесь к нему по HTTP. Также удалённый Piper можно запустить на том же сервере в Docker-контейнере.

ОС и зависимости
ОСLinux (Debian 11+, Ubuntu 22.04+, Raspberry Pi OS Bookworm)
PHP7.4+ (требуются функции exec, proc_open, shell_exec)
FFmpegОпционально, для нормализации громкости (loudnorm) синтезированного аудио
libespeak-ng1Необходима для Piper (фонемный анализатор)
ПамятьМодели medium (~60 МБ) требуют ~200 МБ свободной ОЗУ при синтезе. Модели low — ~100 МБ.
Диск~100 МБ для модуля и библиотек, ~60 МБ на каждую medium-модель, ~500 МБ+ для кэша.

Установка удалённого Piper (piper-tts[http])

Установка и запуск

Выполните эти команды на сервере, который будет работать как TTS-движок (Linux x86_64 / aarch64):

# Установка системных зависимостей
apt update && apt install -y curl wget git libespeak-ng1 libstdc++6 python3-venv python3-dev

# Создание виртуального окружения и установка Piper с поддержкой HTTP
python3 -m venv /opt/piper/venv
/opt/piper/venv/bin/pip install --upgrade pip
/opt/piper/venv/bin/pip install piper-tts[http]

# Скачивание русского голоса Ирина (medium)
/opt/piper/venv/bin/python3 -m piper.download_voices ru_RU-irina-medium

# Запуск HTTP-сервера (порт 5000)
/opt/piper/venv/bin/python3 -m piper.http_server -m ru_RU-irina-medium --host 0.0.0.0 --port 5000
Systemd-сервис

Для автоматического запуска при загрузке системы создайте systemd unit:

cat > /etc/systemd/system/piper.service << 'EOF'
[Unit]
Description=Piper TTS HTTP Server
After=network.target

[Service]
Type=simple
ExecStart=/opt/piper/venv/bin/python3 -m piper.http_server -m ru_RU-irina-medium --host 0.0.0.0 --port 5000
Restart=always
User=root

[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload && systemctl enable --now piper

# Проверка статуса
journalctl -u piper -n 20 --no-pager

# Проверка API
curl http://localhost:5000/voices
Установка дополнительных голосов

Чтобы установить другие голоса (например, мужской голос Денис):

# Установить голос
/opt/piper/venv/bin/python3 -m piper.download_voices ru_RU-denis-medium

# Перезапустить сервер (режим с автовыбором модели из установленных)
systemctl restart piper

На сервере будет доступен голос denis. Модуль MajorDoMo получит обновлённый список через GET /voices после перезапуска.

Системные требования для удалённого сервера
  • Любая 64-битная ОС Linux (Debian, Ubuntu и т.д.)
  • Python 3.9+
  • ~300 МБ свободной ОЗУ на одну модель medium
  • Порт 5000 (или любой другой) должен быть открыт для MajorDoMo-сервера
  • Для слабых устройств (Raspberry Pi 3, Orange Pi) рекомендуется модель качества low

Ручная установка локального Piper

Если автоматическая установка не сработала

Автоматическая установка (кнопка Установить Piper) может не сработать на Raspberry Pi, устаревших версиях ОС, при отсутствии pip или ошибках сборки. В таких случаях установите Piper вручную:

apt update && apt install -y curl wget git libespeak-ng1 libstdc++6 python3-venv python3-dev

git clone https://github.com/OHF-voice/piper1-gpl.git /opt/piper/piper1-gpl
cd /opt/piper/piper1-gpl
python3 -m venv .venv
.venv/bin/pip install --upgrade pip
.venv/bin/pip install .
ln -sf /opt/piper/piper1-gpl/.venv/bin/piper /usr/local/bin/piper

# Скачать русский голос Ирина (medium)
mkdir -p /opt/piper/voices/ru_RU-irina-medium
curl -fSL -o /opt/piper/voices/ru_RU-irina-medium/ru_RU-irina-medium.onnx \
  "https://huggingface.co/rhasspy/piper-voices/resolve/main/ru/ru_RU/irina/medium/ru_RU-irina-medium.onnx"
curl -fSL -o /opt/piper/voices/ru_RU-irina-medium/ru_RU-irina-medium.onnx.json \
  "https://huggingface.co/rhasspy/piper-voices/resolve/main/ru/ru_RU/irina/medium/ru_RU-irina-medium.onnx.json"
chown -R www-data:www-data /opt/piper/voices

# Проверка
echo "Привет, мир!" | /usr/local/bin/piper \
  -m /opt/piper/voices/ru_RU-irina-medium/ru_RU-irina-medium.onnx \
  -c /opt/piper/voices/ru_RU-irina-medium/ru_RU-irina-medium.onnx.json \
  -f /tmp/test.wav && play /tmp/test.wav

Если sox (play) не установлен: apt install -y sox.
