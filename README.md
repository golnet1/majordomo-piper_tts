# Piper TTS — модуль синтеза речи для MajorDoMo

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Превращает любой текст в речь через **Piper** — нейросетевой синтезатор, работающий локально на CPU. Аудио передаётся в браузер через WebSocket и воспроизводится без задержек.

Поддерживает русские голоса: Ирина, Руслан, Денис, Дмитрий. Модели скачиваются из репозитория [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices) нажатием одной кнопки.

---

## Возможности

- 🧠 Полностью локальный синтез (Piper + ONNX Runtime) — ничего не уходит в облако
- 🔊 Автоматическая нормализация громкости через FFmpeg (loudnorm)
- 📦 Кэширование синтезированных фраз (повторные — мгновенно)
- 🧹 Автоудаление редкоиспользуемых кэшированных файлов (10 дней)
- 🎚️ Регулировка скорости и паузы между предложениями
- 📥 Установка/удаление голосовых моделей из админ-панели
- 📊 Прогресс-бар при загрузке моделей (через cURL с весовым расчётом)
- 🔄 Автоустановка Piper (apt + git + pip) при установке модуля
- ⏳ Индикатор статуса установки в реальном времени (жёлтый / зелёный / красный)
- 🌐 Поддержка русского и английского интерфейса

## Требования

| Компонент | Версия / Условие |
|-----------|------------------|
| **ОС** | Linux (aarch64 / x86_64 / amd64) |
| **MajorDoMo** | любая актуальная версия |
| **PHP** | 7.4+ |
| **Piper** | устанавливается автоматически |
| **FFmpeg** | для нормализации громкости (опционально) |
| **Интернет** | при установке модуля (apt, git clone, pip install) |

> Модуль **не работает** на 32-битных системах — Piper требует 64-битную архитектуру.

## Установка

### 1. Скачать архив

Загрузите [`piper_tts.tar.gz`](https://github.com/golnet1/majordomo-piper_tts/releases) через админ-панель MajorDoMo:  
**Администрирование → Управление модулями → Установить модуль из архива**.

> Либо скопируйте файлы вручную:
> ```
> modules/piper_tts/       → /var/www/html/modules/piper_tts/
> templates/piper_tts/     → /var/www/html/templates/piper_tts/
> languages/piper_tts_*.php → /var/www/html/languages/
> img/modules/piper_tts.png → /var/www/html/img/modules/piper_tts.png
> ```

### 2. Установить модуль

Перейдите в **Администрирование → Управление модулями**, найдите `piper_tts` и нажмите **"Установить"**.

При установке:
- Создаются директории `/opt/piper/voices` и `/tmp/piper-tts`
- В `.htaccess` добавляется `php_value auto_prepend_file` для подключения клиентского скрипта
- В фоне запускается установка Piper: `apt` → `git clone` → `python3 -m venv` → `pip install .`
- Скачивается базовая модель **irina-medium** (~60 МБ)

> Первая установка занимает **10–20 минут** (зависит от Raspberry Pi). Статус отображается в админке.

### 3. Подключить плеер в браузере

- **Обычные страницы** — скрипт подключается автоматически через `prepend.php`
- **SPA-панели** (mboard_pro) — добавьте в `index.html` перед `</body>`:
  ```html
  <script src="/templates/piper_tts/js/piper_tts.js"></script>
  ```

## Настройка

В админ-панели модуля доступны:

| Параметр | Описание |
|----------|----------|
| Piper binary | Путь к бинарнику piper (`/usr/local/bin/piper`) |
| Модель | Выбор активной голосовой модели |
| Скорость | Коэффициент длины (0.5–1.5, где 1.0 — норма) |
| Пауза между предложениями | Тишина между предложениями в секундах (0–0.5) |
| Кэш | Включение/выключение кэширования WAV |
| Автоочистка кэша | Удаление файлов старше 10 дней (толчок обновляет mtime) |

## Использование

После установки отправьте событие `SAY` через любой механизм MajorDoMo (сценарий, PHP-код, веб-хук). Модуль:

1. Получает текст из события
2. Очищает от пунктуации
3. Синтезирует через Piper (или берёт из кэша)
4. Нормализует громкость через FFmpeg
5. Отправляет URL WAV-файла в браузер через WebSocket
6. Клиентский скрипт воспроизводит аудио
